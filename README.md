# 🏏 Cricket Bat E-Commerce Website

Welcome to my *Cricket Bat E-Commerce Website*! 🏏🔥

A modern and responsive React-based website designed for cricket lovers to explore and select their favorite cricket bats. 🛒✨

## 🌟 Features

- 🏏 Cricket Bat Product Collection
- 🖼️ Product Images
- 💰 Product Price Display
- 🛒 Add to Cart Functionality
- 🔢 Cart Quantity Management
- 💵 Total Amount Calculation
- 📦 Product Details
- 🎨 Clean & Attractive UI
- 📱 Responsive Design
- ⚡ Fast React + Vite Application

## 🛠️ Technologies Used

- ⚛️ React.js
- ⚡ Vite
- 🎨 CSS3
- 🟨 JavaScript
- 🛒 React State Management
- 🧭 React Router DOM
- 📦 JSON Product Data
